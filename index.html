CONFIGURADOR DE BANCO

Passo a passo (Supabase)
  1. Acesse o projeto no painel do Supabase.
  2. Em Settings → API, copie a Project URL e cole em URL do Projeto Supabase.
  3. Nessa mesma tela, copie o Project ID / Reference para Project Ref.
  4. Use Schema REST como public (ou o schema customizado da API).
  5. Em Project Settings → API Keys, copie anon public (opcional) e service_role.
  6. Confirme os nomes das tabelas no Table Editor: normalmente projects e tap_entries.
  7. Revise os dados e clique em Salvar Conexão.

Acesso protegido por senha mestre.
