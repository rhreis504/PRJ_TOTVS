Este HTML usa Google Identity/OAuth para ler planilha privada. Não é Apps Script e não exige publicar a planilha na Web.
Obrigatório para planilha privada. O origin autorizado deve incluir http://localhost:8000 ou o domínio onde este HTML estiver hospedado.
O HTML buscará todas as abas, exceto as ignoradas. O projeto será identificado por coluna equivalente ou pelo nome da aba quando não existir coluna de projeto.
Se a planilha for muito grande, reduza os limites para melhorar a performance.
Alternativa manual. O importador lê todas as abas do XLSX/CSV e aplica a mesma regra de abas ignoradas.
